# Support

Start with the [setup guide](docs/agent-setup.md), [troubleshooting](docs/troubleshooting.md), and [documentation index](docs/README.md).

For a reproducible bug, use the repository's bug report template. Include the revision, mode (mock/live), platform, steps and sanitized error. Never attach `.env`, connection JSON, raw OAuth URLs, a phone number, mailbox data or a database.

For credentials, billing, Apple provisioning and provider access, use the relevant account's support channel. This repository does not provide a hosted public service or support SLA. Security issues follow [SECURITY.md](SECURITY.md).
